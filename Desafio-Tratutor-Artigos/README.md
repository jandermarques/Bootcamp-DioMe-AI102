# Bootcamp-DioMe-AI102

## Desafio: Tradutor de Artigos com Azure OpenAI Foundry
Este desafio propõe a criação de um tratutor de artigos utilizando o modelo de linguagem do Azure OpenIA. Para a solução do desafio foi implementado no programa 'Desafio_Tradutor.ipynb' a extração de uma URL, tradução do conteúdo com o consumo de uma API e manipulção do resultado.
